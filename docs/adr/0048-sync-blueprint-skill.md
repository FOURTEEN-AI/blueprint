# 0048. /sync-blueprint for upstream template updates

- Status: Accepted
- Date: 2026-10-14

## Context

Generated projects should benefit from later improvements to blueprint (skills, CI fixes) without being re-created.

## Decision

- `/bootstrap` records the blueprint version (commit) in a **`.blueprint`** metadata file.
- A **`/sync-blueprint` skill** compares the project with upstream blueprint from that commit onward, proposes merging changes to the kit, CI and build, skips application code, and updates the recorded commit.

## Consequences

- Projects can keep up with blueprint at their own pace.
- Because changes are proposed by an agent rather than generated by a template engine, results can vary. Changes go through a normal PR.
